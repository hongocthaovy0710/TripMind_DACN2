# Frontend Admin

Ứng dụng React + TypeScript + Vite độc lập cho khu vực quản trị. Hiện có dashboard khởi đầu, React Router và cấu hình Axios; chưa có dữ liệu giả hoặc nghiệp vụ quản trị.

```bash
npm install
npm run dev
npm run build
```

Sao chép `.env.example` thành `.env.local` để đặt `VITE_API_BASE_URL` (mặc định `http://localhost:8080`).
