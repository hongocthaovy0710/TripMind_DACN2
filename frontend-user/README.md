# Frontend User

Ứng dụng React + TypeScript + Vite dành cho người dùng. Đã có trang khởi đầu và cấu hình React Router/Axios; các luồng nghiệp vụ sẽ được bổ sung sau khi nhóm thống nhất yêu cầu.

```bash
npm install
npm run dev
npm run build
```

Sao chép `.env.example` thành `.env.local` để đặt `VITE_API_BASE_URL` (mặc định `http://localhost:8080`).
